Automatic Plant Watering System Using Arduino Uno

Project Description: -
This project automatically waters plants when the soil becomes dry. It uses an Arduino Uno and a soil moisture sensor to monitor soil conditions. When the soil moisture is low, the water pump turns ON automatically. When sufficient moisture is reached, the pump turns OFF.

Components Used: -
- Arduino Uno
- Soil Moisture Sensor
- Water Pump
- Relay Module
- Jumper Wires
- Power Supply
- Connecting Pipes

Working Principle:-
The soil moisture sensor detects the moisture level in the soil and sends the information to Arduino Uno. Arduino controls the water pump through a relay module. The pump supplies water automatically when the soil is dry.

Applications:-
- Home gardening
- Agriculture
- Greenhouses
- Plant nurseries

Advantages: -
- Saves water
- Reduces manual work
- Easy to use
- Provides automatic watering
